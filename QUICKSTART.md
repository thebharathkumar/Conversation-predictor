# 🚀 Quick Start Guide - Digital Therapist AI

Get up and running in 5 minutes!

## Step 1: Install Python Dependencies

```bash
pip install -r requirements.txt
```

## Step 2: Set Up Your API Key

1. Get an API key from https://console.anthropic.com/
2. Create a `.env` file:

```bash
cp .env.example .env
```

3. Edit `.env` and add your key:

```
ANTHROPIC_API_KEY=sk-ant-your-key-here
```

## Step 3: Run the App

```bash
python main.py
```

## Step 4: Start Your First Session

1. Select option `1` - Start Therapy Session
2. Talk about anything on your mind
3. Type `end` when you're done

## Step 5: Generate Your First Report

1. After a few sessions, select option `2` - Generate Monthly Report
2. Enter current year and month
3. Choose `visual` format for charts

That's it! 🎉

## Quick Commands During Session

- `sleep` - Log sleep data
- `end` - End session
- `Ctrl+C` - Exit
